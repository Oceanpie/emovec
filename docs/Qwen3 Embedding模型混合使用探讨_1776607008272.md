### 🚫 为什么不能直接混合？
*   **语义空间的“扭曲”**：简单来说，不同大小的模型，就像是**同一座城市的不同比例地图**。尽管它们描绘的是同一片土地（理解语义），但街道、地标的相对位置和距离感完全不同[reference:0]。直接比对，结论自然是错的。
*   **向量维度的“鸿沟”**：Qwen3系列不同参数量的模型，其默认的向量维度是不同的。例如0.6B模型默认输出1024维向量，4B模型是2560维，而8B模型是4096维[reference:1]。它们的向量长度都不同，无法直接进行相似度计算[reference:2]。

### 🤝 如何“间接”混合使用？
虽然不能直接混用，但有一些“曲线救国”的方案：
*   **Matryoshka表示学习 (MRL)**：这是最推荐的方式。Qwen3-Embedding系列原生支持MRL，你可以将其看作一个 **“俄罗斯套娃”** [reference:3]。它能让你在保留高维向量的同时，直接**从高维向量中“切”出低维子向量**使用，保证了向量空间的一致性[reference:4]。配合使用0.6B的1024维、4B的2560维、8B的4096维作为基础库，并统一截取前512维组成混合索引，但务必验证其对齐效果。
*   **向量空间对齐 (Procrustes)**：一种“翻译”技术[reference:5]。你需要挑选一组相同的中文文本（如1000条新闻标题），分别用不同模型生成向量。然后利用这组“对齐”的向量，求解一个能将其中一个空间“旋转/映射”到另一个空间的线性变换矩阵[reference:6]。

总的来说，虽然直接混合不同参数的模型不可行，但借助MRL机制和对齐技术，你仍然可以在一些特定场景中灵活组合使用它们。当然，在大多数生产环境中，为了稳定和简单，选择一个固定模型仍然是首选。

```python
import numpy as np
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error
import warnings

def auto_polynomial_fit(t, y, max_degree=10):
    """
    自动选择最优多项式次数（基于BIC）
    返回: (coeffs, degree, r2)  coeffs从常数项到最高次
    """
    best_bic = np.inf
    best_model = None
    best_degree = 1
    n = len(t)
    
    for d in range(1, max_degree+1):
        # 构造多项式特征
        poly = PolynomialFeatures(degree=d, include_bias=True)
        X = poly.fit_transform(t.reshape(-1, 1))
        
        # 拟合线性回归
        model = LinearRegression(fit_intercept=False)  # 因为已经包含偏置项
        model.fit(X, y)
        y_pred = model.predict(X)
        
        # 计算BIC
        mse = mean_squared_error(y, y_pred)
        k = d + 1  # 参数个数（包括常数项）
        bic = n * np.log(mse) + k * np.log(n)
        
        if bic < best_bic:
            best_bic = bic
            best_model = model
            best_degree = d
    
    # 提取系数
    coeffs = best_model.coef_
    r2 = best_model.score(X, y)
    return coeffs, best_degree, r2

def fit_emotion_curve(emotion_vectors, max_degree=10):
    """
    输入: emotion_vectors - N x 8 numpy数组，每行是一个句子的8维情感向量
    输出: 每个维度的多项式表达式字符串和系数
    """
    N = emotion_vectors.shape[0]
    t = np.arange(N)  # 时间索引，也可以换成实际阅读时间
    
    results = []
    for dim in range(8):
        y = emotion_vectors[:, dim]
        coeffs, degree, r2 = auto_polynomial_fit(t, y, max_degree)
        # 构造表达式字符串
        terms = [f"{coeffs[0]:.4f}"]
        for i in range(1, degree+1):
            term = f"{coeffs[i]:+.4f} * t^{i}"
            terms.append(term)
        expr = " ".join(terms)
        results.append({
            "dimension": dim,
            "expression": expr,
            "degree": degree,
            "r2": r2,
            "coeffs": coeffs[:degree+1]
        })
    return results
```

```python
import numpy as np
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error

def auto_vector_polynomial(t, Y, max_degree=10):
    """
    t: (N,) 时间索引
    Y: (N, 8) 情感向量序列
    返回: coeffs_list (list of (degree+1)个8维向量), degree, r2
    """
    best_bic = np.inf
    best_coeffs = None
    best_degree = 1
    n = len(t)
    
    for d in range(1, max_degree+1):
        poly = PolynomialFeatures(degree=d, include_bias=True)
        X = poly.fit_transform(t.reshape(-1, 1))  # (N, d+1)
        
        # 对每个输出维度独立求解，但系数矩阵统一
        model = LinearRegression(fit_intercept=False)
        model.fit(X, Y)  # Y是(N,8)，coef_形状为(d+1, 8)
        Y_pred = model.predict(X)
        
        mse = np.mean((Y - Y_pred)**2)  # 整体均方误差
        k = (d+1) * 8  # 参数总数（8个维度 × (d+1)个系数）
        bic = n * np.log(mse) + k * np.log(n)
        
        if bic < best_bic:
            best_bic = bic
            best_coeffs = model.coef_  # shape (d+1, 8)
            best_degree = d
    
    # 计算最终R²
    poly_best = PolynomialFeatures(degree=best_degree, include_bias=True)
    X_best = poly_best.fit_transform(t.reshape(-1, 1))
    Y_pred_best = X_best @ best_coeffs
    ss_res = np.sum((Y - Y_pred_best)**2)
    ss_tot = np.sum((Y - np.mean(Y, axis=0))**2)
    r2 = 1 - ss_res/ss_tot
    
    return best_coeffs, best_degree, r2

# 输出一个表达式
```

```python
class EmotionStructureEvaluator:
    def __init__(self, window_size=5, stride=1):
        self.window_size = window_size
        self.stride = stride

    def sentence_level(self, vectors):
        """vectors: (N, 8)"""
        norms = np.linalg.norm(vectors, axis=1)
        # 情感熵
        probs = np.abs(vectors) / (norms[:, None] + 1e-8)
        entropy = -np.sum(probs * np.log(probs + 1e-8), axis=1)
        # 主要情感纯度（最大分量占比）
        max_ratio = np.max(probs, axis=1)
        return {"norms": norms, "entropy": entropy, "max_ratio": max_ratio}

    def window_level(self, vectors):
        N = len(vectors)
        features = []
        for start in range(0, N - self.window_size + 1, self.stride):
            window = vectors[start:start+self.window_size]
            # 计算窗口内相邻句子的平均余弦距离
            diffs = []
            for j in range(len(window)-1):
                cos_sim = np.dot(window[j], window[j+1]) / (np.linalg.norm(window[j])*np.linalg.norm(window[j+1])+1e-8)
                diffs.append(1 - cos_sim)
            avg_dist = np.mean(diffs)
            # 窗口内情感向量的标准差（各维度的std均值）
            std_mean = np.mean(np.std(window, axis=0))
            # 窗口首尾变化
            start_end_dist = np.linalg.norm(window[-1] - window[0])
            features.append([avg_dist, std_mean, start_end_dist])
        return np.array(features)

    def global_level(self, vectors, window_features):
        # 整体自相关
        from scipy.signal import correlate
        # 示例：计算8维平均的自相关 lag1
        corr_sum = 0
        for d in range(8):
            corr_sum += np.corrcoef(vectors[:-1,d], vectors[1:,d])[0,1]
        mean_autocorr = corr_sum / 8
        # 异常窗口比例（假设窗口距离 > 某阈值）
        threshold = np.percentile(window_features[:,0], 75)
        abnormal_ratio = np.mean(window_features[:,0] > threshold)
        return {"mean_autocorr": mean_autocorr, "abnormal_window_ratio": abnormal_ratio}
```

| 表示 | 记法 | 生成方式 |
|------|------|----------|
| 聚合向量 | \( \mathbf{w}_{\text{agg}} \) | 对窗口内所有句子的 8 维向量取**算术平均**（或加权平均，权重为句子强度） |
| 整体向量 | \( \mathbf{w}_{\text{holo}} \) | 将窗口内所有句子按原文顺序拼接成一个文本（保留标点），直接输入 Embedding 模型得到 8 维向量 |

### 2.3 窗口级指标

| 类别 | 指标 | 计算方法 | 用途 |
|------|------|----------|------|
| **内部连贯性** | 句子间平均余弦距离 | 窗口内相邻句子向量的 1 - 余弦相似度的均值 | 数值越小越平滑 |
| **内部变化幅度** | 窗口内句子向量模长的标准差 | \( \text{std}(\|\mathbf{v}_j\|) \) | 反映情感波动剧烈程度 |
| **聚合 vs 整体一致性** | 余弦相似度 \( \cos(\mathbf{w}_{\text{agg}}, \mathbf{w}_{\text{holo}}) \) | 直接计算 | 若很低，说明窗口内有非线性的情感叠加（如反讽、转折） |
| **整体情感强度** | \( \|\mathbf{w}_{\text{holo}}\| \) | 窗口整体的情感饱满度 | |
| **整体情感纯度** | 同句子级纯度，但作用于 \( \mathbf{w}_{\text{holo}} \) | | |
| **情感趋势** | 对窗口内每个维度的句子向量序列做线性回归，斜率均值 | 正值为上升，负值为下降 | |
| **异常突变计数** | 相邻句子距离超过全局阈值（如所有句子距离的 75% 分位数）的次数 | | |

**输出文件**：`window_level.csv`，每个窗口一行，包含窗口起止句子索引及上述指标。

---

## 三、整体级评估（整个文本一个汇总报告）

将句子级和窗口级的特征聚合，得到全文的“情感结构质量”评分。

| 指标 | 计算方法 | 说明 |
|------|----------|------|
| **情感轨迹复杂度** | 全文情感向量的样本熵（对 8 维分别计算后取平均） | 太高表示随机噪声，太低表示单调 |
| **全局自相关性** | 每个维度 lag=1 自相关系数的平均值 | 衡量情感的记忆长度 |
| **情感维度协同合理性** | 计算 8 个维度的皮尔逊相关系数矩阵，与标准情感模型（如普拉奇克轮）的相关系数矩阵的余弦相似度 | 检验情感逻辑是否“正常” |
| **异常窗口比例** | 窗口级指标中“聚合 vs 整体一致性”低于阈值（如 0.5）的窗口占比 | 高比例可能意味着全文充满反讽或矛盾情感 |
| **情感多样性** | 全文所有句子向量的协方差矩阵的行列式（或迹） | 反映情感状态覆盖的空间体积 |
| **情感节奏规律性** | 对情感强度序列做傅里叶变换，计算主频能量占比 | 人类写作通常有低频主峰 |

**输出**：一个 JSON 或表格，包含以上指标及一个**综合得分**（可自定义加权公式）。

## 四、实现流程（伪代码）

```python
# 1. 输入文本分句
sentences = split_paragraphs(text)   # list of str, length N

# 2. 用 Embedding 模型得到每个句子的 8 维向量

# 3. 句子级评估
sentence_features = compute_sentence_level(sentence_vecs)

# 4. 窗口级评估（设 window_size=5, stride=1）
windows = sliding_windows(sentences, sentence_vecs, window_size=5, stride=1)
window_features = []
for win_sents, win_vecs in windows:
    # 聚合向量
    agg_vec = np.mean(win_vecs, axis=0)
    # 整体向量：拼接文本
    holo_vec = model.encode([" ".join(win_sents)])[0]   # 注意长度限制
    # 计算指标
    feat = compute_window_metrics(win_vecs, agg_vec, holo_vec)
    window_features.append(feat)

# 5. 整体级评估
global_features = compute_global_metrics(sentence_vecs, window_features)

# 6. 输出报告
save_csv(sentence_features, "sentence_level.csv")
save_csv(window_features, "window_level.csv")
save_json(global_features, "global_report.json")
```

# 文本情感结构评估的可视化方案（无代码）

## 一、句子级可视化

### 1.1 情感强度曲线图
- **横轴**：句子序号（按顺序）。
- **纵轴**：情感向量模长（强度）。
- **图形**：折线图，可叠加不同颜色的点表示主导情感类型。
- **用途**：一眼看出哪些句子情感强烈，整体起伏趋势。

### 1.2 情感纯度堆叠条
- **每个句子**：一个堆叠的水平条，长度代表情感强度，不同颜色段代表各维度的占比（归一化后的绝对值）。
- **横排展示**：所有句子依次排列，形成“情感光谱带”。
- **用途**：快速识别情感混杂（多色）或单一（单色）的句子。

### 1.3 情感雷达图序列（仅关键句子）
- 只选取强度最高、纯度最低、或标记为“矛盾”的句子，为每个句子画一个8维雷达图。
- **展示方式**：按句子顺序排列成多张小图，或做成可点击的交互图（在报告中用缩略图）。

---

## 二、窗口级可视化（核心创新）

### 2.1 两种向量的平行坐标对比
- **每个窗口**：用平行坐标图同时画出“聚合向量”和“整体向量”的8个维度值。
- **展示方式**：将所有窗口的平行坐标图按窗口顺序排布，或制作成动态切换（鼠标悬停显示对比）。
- **用途**：直观看到哪些窗口的聚合向量与整体向量差异大（线形错开），暗示反讽或非线性情感。

### 2.2 窗口热力图
- **横轴**：窗口序号（时间顺序）。
- **纵轴**：8个情感维度。
- **颜色**：表示该窗口“整体向量”在该维度的强度（热色高，冷色低）。
- **叠加标记**：在热力图上用圆圈或星号标记“聚合-整体一致性低”的窗口位置。
- **用途**：宏观观察情感维度随时间的变化，同时定位异常窗口。

### 2.3 窗口内句子情感轨迹 + 整体向量箭头
- **对单个窗口**：在一个2D散点图（用PCA或UMAP将8维投影到2D）中，画出窗口内每个句子的向量点（小圆点），并用线条连接顺序。
- **叠加**：在该图中画出“聚合向量”点（方块）和“整体向量”点（星形），并标注两者之间的距离。
- **用途**：精细分析一个窗口内部的情感流动，以及宏观整体如何偏离微观平均。

### 2.4 滑动窗口一致性曲线
- **横轴**：窗口起始句子序号。
- **纵轴**：聚合向量与整体向量的余弦相似度。
- **图形**：折线图，加一条阈值线（例如0.7）。
- **用途**：识别全文中哪些段落存在“局部平均无法代表整体”的现象，常用于检测讽刺、转折、铺垫爆发结构。

## 三、整体级可视化

### 3.1 情感轨迹三维动画（你之前设想的）
- **坐标轴**：横轴 t（时间/句子序号），纵轴 x（合向量x分量），竖轴 y（合向量y分量）。
- **动画**：随着t增加，一条空间曲线向前延伸，可用颜色表示情感强度或纯度。
- **用途**：整体情感流动的“雕塑”感，适合做视频展示。

### 3.2 情感维度相关性矩阵图
- **8×8方格**，颜色表示该行维度与该列维度的皮尔逊相关系数（红色正相关，蓝色负相关）。
- **叠加**：在旁边附上一个“标准情感模型”的相关性矩阵（如普拉奇克轮的理论预期），做视觉对比。
- **用途**：判断本文的情感逻辑是否“正常”。

### 3.3 情感轨迹的频谱图
- **横轴**：频率（低频到高频）。
- **纵轴**：功率谱密度（对情感强度序列做傅里叶变换）。
- **图形**：折线图或柱状图，标注主频位置。
- **用途**：揭示情感节奏的主周期（例如每10句话一次情感高潮）。

### 3.4 综合得分仪表盘
- **雷达图**：将整体级指标（自相关性、异常窗口比例、情感多样性、复杂度等）标准化后画在一个雷达图上。
- **总分**：大号数字显示在中央。
- **用途**：一图总结全文情感结构质量。
