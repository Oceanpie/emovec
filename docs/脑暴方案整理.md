## 方案 A：情感轨迹拟合函数

**状态：完整，可落地**

### 核心思路

对一篇文章的每句话计算 8D 情感向量，得到离散序列 v₁, v₂, ..., vₙ。拟合出连续的向量值多项式函数 **f(t)**，表征该文章的情感变化轨迹。

### 数学形式

```
f(t) = c₀ + c₁t + c₂t² + ... + cₖtᵏ
```

- 每个 cᵢ 是一个 8 维常向量
- k 由 BIC（贝叶斯信息准则）自动选择（尝试 1~10 次，平衡精度与复杂度）
- 无需手动调参，输入向量序列即可自动输出表达式

### 本质

8 个维度各自独立拟合一条多项式曲线，共享自变量 t（句序），打包成一个向量函数。t 不是"控制"情感，只是描述性的时间标记。

### 拟合函数能做什么

| 用途 | 方法 |
|---|---|
| 情感变化速度 | 一阶导数 f'(t) |
| 情感加速度 | 二阶导数 f''(t) |
| 情感高潮检测 | 导数极值点 / 曲率最大点 |
| 情感轮廓分类 | 对函数做聚类（先抑后扬、U 型悲剧、波浪型…） |
| 突变点检测（函数层面） | 导数峰值处为叙事结构层面的转折点 |
| 突变点检测（数据层面） | 相邻句向量的欧氏/余弦距离超阈值 |
| 文章比较 | 两篇文章函数间的 L² 距离或 DTW |
| 角色对比 | 分别提取不同角色对话的向量，拟合各自的函数 |
| 风格/作者识别 | 计算函数距离，判断情感节奏是否相似 |

### 性能

- 125 句 × 10 次多项式 BIC 搜索：**毫秒到几十毫秒**（CPU）
- 瓶颈在 embedding 推理，不在拟合

### 局限

- 多项式会**平滑掉局部突变**（讽刺、急转）
- **外推不可靠**，只用于内插描述已有文章
- 情感波动剧烈时可能选到 8~10 次多项式，表达式变长

### 应用举例

> "在句子序号 237 到 245 之间，悲伤维度的斜率达到了 2.3（全篇最高），同时愤怒维度也同步上升了 0.8，形成了独特的'悲愤交织'模式。"

## 方案 B：三维情感轨迹动画

**状态：完整，可落地**

### 核心思路

将 8D 情感向量序列映射为三维空间中的连续曲线，做成动画展示情感流动。

### 映射方法

**8 维 → 2 维**：定义 8 个二维单位向量均匀分布在单位圆上（相邻夹角 45°）：

```
uₖ = (cos θₖ, sin θₖ),  θₖ = 2π(k-1)/8,  k=1..8
```

每个时刻 t 的合向量：

```
p(t) = Σ vₖ(t) · uₖ    → 得到二维坐标 (x(t), y(t))
```

**加入时间轴**：三维坐标系 —— 横轴 t（句序），纵轴 x，竖轴 y。每个时刻对应点 (t, x(t), y(t))。

### 可视化效果

- 曲线从 t=0 出发，逐渐向右延伸，同时在 x-y 平面内移动
- 旋转视角：侧面看 t-x 剖面是某维度曲线，顶看是 x-y 平面的情感轨迹
- 可用颜色映射表示时间进度或情感强度

### 进阶增强

- 颜色渐变（冷→暖）表示时间
- 当前点处画小箭头表示瞬时运动方向（导数方向）
- 交互式（plotly）：可旋转、可缩放、点击显示原文句子
- 标记特殊事件点（高潮）用大点

## 方案 C：立方体空间分布图

**状态：完整，可落地**

### 核心思路

将 8D 情感向量投影到三维立方体空间，展示一系列情感向量在空间中的分布（静态散点图，非动画）。

### 映射方法

取立方体 8 个顶点方向作为基向量：

```
uₖ = (±1, ±1, ±1) / √3,  k=1..8
```

投影公式：

```
p = Σ vₖ · uₖ    → 得到三维坐标 (x, y, z)
```

### 从分布中能看出什么

| 模式 | 含义 |
|---|---|
| 聚集在小区域 | 整篇文章情感状态一致（如悲伤基调） |
| 散布范围大 | 情感变化剧烈 |
| 偏向某个角 | 对应情感维度组合主导（如喜悦+信任+期待） |
| 按时间连线 | 情感轨迹在立方体内的流动 |

### 增强

- 画出立方体线框辅助观察
- 颜色表示时间顺序
- plotly 交互式：可旋转、点击查看句子索引

## 方案 D：情感结构质量量化指标体系

**状态：完整，可落地**

### 背景

AI 生成的文字单句情感可能强烈，但整体"寡淡如水"。需要一套量化指标来表征情感结构的"连贯性"。

### 指标体系

#### 1. 突变率（局部不连贯程度）

- 计算相邻句情感向量的余弦/欧氏距离，得到差值序列 dₜ
- **突变比例**：dₜ 超过阈值（如 75% 分位数）的比例
- **突变幅度峰度**：kurtosis(dₜ)，越高说明少数巨大突变主导

#### 2. 情感自相关性（情感记忆长度）

- 对每个维度计算 lag=1,2,3 自相关系数，取 8 维平均
- ρ₁ = (1/8) Σ corr(v_d[1:], v_d[:-1])
- 比较 ρ₁ 和 ρ₃ 的比值看衰减速度

#### 3. 跨维度协同性（情感维度逻辑一致性）

- 计算所有句子中 8 维的两两皮尔逊相关矩阵 (8×8)
- 与标准情感模型（如 Plutchik 轮）的相关矩阵做余弦相似度
- 或预设"常识协同对"（愤怒-恐惧正相关，喜悦-悲伤负相关），计算一致性

#### 4. 波形复杂度

- **转折点密度**：局部极值点数量 / 总长度
- **高频能量占比**：对每个维度做傅里叶变换，高频分量能量占比
- **样本熵**：衡量序列自相似性

#### 5. 综合指标：情感连贯性得分（ECS）

```
ECS = w₁·(1-spike_ratio) + w₂·ρ₁ + w₃·plausibility - w₄·noise_energy
```

权重可通过少量人工标注的人类/AI 样本做逻辑回归学习。

### 重要提醒

**以上所有方向都只是假说，不是定论。** 完全可能反过来。正确做法是：收集样本 → 计算指标 → 统计检验 → 看实际差异方向。

## 方案 E：三层评估框架（句子级 / 窗口级 / 整体级）

**状态：完整，可落地**

### 目标

对任意文本（如小说章节），从三个层次量化情感表达的连贯性、逻辑性与丰富度。

### 核心创新

窗口级同时使用两种向量表示，对比差异揭示情感结构特征：
- **聚合向量**：窗口内各句向量取均值
- **整体向量**：窗口内所有文本拼接后直接编码

### 一、句子级评估（每句一个记录）

| 指标 | 计算方法 | 输出 |
|---|---|---|
| 情感强度 | 向量模长 ‖vᵢ‖ | 标量 |
| 情感纯度 | 1 - 归一化熵：`purity = 1 + Σpₖ log pₖ / log 8`，pₖ = \|vᵢₖ\| / ‖vᵢ‖ | 标量 (0~1) |
| 主导情感 | 绝对值最大的维度索引及强度 | 索引 + 强度 |
| 合理性标志 | 预设规则（如喜悦与悲伤同时 >0.5 标记"矛盾"） | 布尔/严重程度 |

### 二、窗口级评估（固定 L 句，可重叠或非重叠）

**两种向量表示**：

| 表示 | 记法 | 生成方式 |
|---|---|---|
| 聚合向量 | w_agg | 窗口内各句 8D 向量取算术平均 |
| 整体向量 | w_holo | 窗口文本拼接后直接输入 Embedding 模型 |

**窗口级指标**：

| 类别 | 指标 | 计算方法 | 用途 |
|---|---|---|---|
| 内部连贯性 | 句子间平均余弦距离 | 相邻句 1-余弦相似度均值 | 越小越平滑 |
| 内部变化幅度 | 模长标准差 | std(‖vⱼ‖) | 情感波动剧烈程度 |
| 聚合 vs 整体一致性 | 余弦相似度 cos(w_agg, w_holo) | 直接计算 | 低值 = 非线性情感叠加（反讽/转折） |
| 整体情感强度 | ‖w_holo‖ | | 窗口整体饱满度 |
| 整体情感纯度 | 同句子级纯度，作用于 w_holo | | |
| 情感趋势 | 每维度线性回归斜率均值 | | 正=上升，负=下降 |
| 异常突变计数 | 相邻句距离超过全局阈值次数 | | |

**参数建议**：
- 窗口长度 L：5~10 句（覆盖一个自然段落）
- 步长 S：L（非重叠，简单快速）或 1（连续分析，做热力图）

### 三、整体级评估（全文一个汇总报告）

| 指标 | 计算方法 | 说明 |
|---|---|---|
| 情感轨迹复杂度 | 样本熵（8 维分别算取平均） | 太高=噪声，太低=单调 |
| 全局自相关性 | 每维度 lag=1 自相关系数均值 | 情感记忆长度 |
| 情感维度协同合理性 | 8 维皮尔逊相关矩阵 vs 标准情感模型的余弦相似度 | 情感逻辑是否"正常" |
| 异常窗口比例 | 聚合-整体一致性低于阈值的窗口占比 | 高=全文反讽或矛盾 |
| 情感多样性 | 所有句向量协方差矩阵的行列式（或迹） | 情感覆盖的空间体积 |
| 情感节奏规律性 | 情感强度序列傅里叶变换，主频能量占比 | 人类通常有低频主峰 |

### 输出

- `sentence_level.csv`：每行一句
- `window_level.csv`：每行一个窗口
- `global_report.json`：全文汇总 + 综合得分

## 方案 G：AI 文本 vs 人类文本的情感差异假说

**状态：假说，需实验验证**

### 核心观察

AI 生成的大段文字，人类觉得"寡淡如水"，但拆成单句计算情感向量时各分量往往不低。为什么？

### 假说

1. **情感向量只测量"当下"不测量"预期"**：向量独立计算每句，不考虑上下文铺垫
2. **AI 缺乏情感逻辑**：句子之间情感跳跃无因果链，上一句开心下一句痛哭再下一句平静
3. **缺乏对比度和节奏**：每句都中等偏高情感强度 = 一条直线，没有低谷就没有高潮
4. **维度间无意义混搭**：同时高喜悦高悲伤但来源毫无关联，读者觉得混乱而非复杂

### 验证方法

1. 收集样本：10 篇公认"情感动人"的人类短篇 + 10 篇 AI 模仿同主题
2. 计算方案 D 中的指标（突变率、自相关、维度协同等）
3. 统计检验（t 检验），看哪些指标有显著差异及方向
4. **不预设方向**——假说可能完全反过来

## 方案 H：商业化方向探讨

**状态：脑暴，未定论**

### 核心定位

手里是**情感分析工具**（不是情感陪伴），价值在**数据洞察**而非交互过程。

### 方向一：面向创作者

- 情绪驱动的写作助手：不只展示曲线，还给出建议（"愤怒值过高，建议下章加安慰桥段"）
- 市场盘有限，客单价低

### 方向二：面向普通用户

- 聊天记录情绪复盘：上传聊天记录，分析冲突点，给出沟通建议
- 单次报告付费（类似基因检测报告模式）

### 方向三：B2B2C 中间件

- 卖给写作平台（起点/番茄），提供"情感诊断"增值服务
- 卖给心理健康 App，提供"情绪洞察"功能
- 卖给社交平台，分析互动情绪演变
- 按 API 调用量或授权收费

### 方向四：小而美付费工具

- 定位：严肃写作者、日记爱好者、自我量化人群
- 功能：离线分析、隐私优先、多维度可视化、导出报告
- 收费：年费订阅（$20-50/年），用户量不大但忠诚度高

### 结论

纯 C 端很难赚大钱。技术最大商业价值可能在 B 端或 B2B2C，作为中间件嵌入已有场景。
